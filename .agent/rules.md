# Regras Persistentes do Usuário

Estas regras devem ser seguidas estritamente pelo Agente Antigravity em todas as interações.

1.  **Língua:** Sempre conversar em Português (PT-BR).
2.  **Painel de Controle PROIBIDO:**
    *   NUNCA logar o usuário automaticamente na organização "Painel de Controle" ou com slug `painel-master`.
    *   Se o sistema detectar que o usuário vai ser redirecionado para lá, INTERCEPTAR e redirecionar para `access-fisioterapia`.
    *   Considerar o Painel de Controle como uma "zona morta" para operação diária.
3.  **Questionários:** NUNCA apagar questionários ao limpar formulários. Questionários (QuickDASH, LEFS, etc.) são entidades separadas e devem ser preservados.
4.  **Cuidado na Modificação:** Sempre fazer modificações com cuidado, analisando em detalhes se a modificação vai ocasionar alguma perda de função ativa e funcional.
