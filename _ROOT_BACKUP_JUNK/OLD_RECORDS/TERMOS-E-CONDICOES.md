## 5. ARMAZENAMENTO E RETENÇÃO DE DADOS

### ⚠️ **IMPORTANTE - LEIA COM ATENÇÃO**

**5.1. Dados em Plano Trial/Teste**:

**TODOS OS DADOS INSERIDOS DURANTE O PERÍODO TRIAL SERÃO ARMAZENADOS EM UM BANCO DE DADOS TEMPORÁRIO E SERÃO AUTOMATICAMENTE EXCLUÍDOS APÓS 60 DIAS DO TÉRMINO DO PERÍODO TRIAL, CASO VOCÊ NÃO MIGRE PARA UM PLANO PAGO.**

**5.2. Período de Retenção**:
- **Plano Trial**: Dados mantidos por **60 dias** após o fim do trial
- **Plano Pago Ativo**: Dados mantidos indefinidamente enquanto a assinatura estiver ativa
- **Plano Pago Cancelado**: Dados mantidos por **90 dias** após o cancelamento

**5.3. Avisos de Exclusão**:
- Você receberá avisos por email nos seguintes momentos:
  - **7 dias** antes do fim do período trial
  - **3 dias** antes do fim do período trial
  - **1 dia** antes do fim do período trial
  - **7 dias** antes da exclusão definitiva dos dados
  - **3 dias** antes da exclusão definitiva dos dados
  - **1 dia** antes da exclusão definitiva dos dados

**5.4. Exclusão Definitiva**:
- Após o período de retenção, **TODOS OS DADOS SERÃO PERMANENTEMENTE EXCLUÍDOS**
- **NÃO SERÁ POSSÍVEL RECUPERAR OS DADOS APÓS A EXCLUSÃO**
- A exclusão inclui, mas não se limita a:
  - Pacientes e prontuários
  - Agendamentos e histórico
  - Avaliações e relatórios
  - Documentos e anexos
  - Configurações da organização

**5.5. Backup e Exportação**:
- Você é responsável por fazer backup de seus dados
- A Plataforma oferece ferramentas de exportação de dados
- Recomendamos exportar seus dados regularmente
